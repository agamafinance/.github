# Agama Finance

Private credit yield infrastructure.

Users deposit USDC into curated vaults and receive **agUSD**, a composable synthetic dollar backed by diversified real-world credit pools from vetted originators. Staking agUSD produces **sagUSD**, which appreciates as private credit repayments generate returns on-chain.

**[agama-soroban](https://github.com/agamafinance/agama-soroban)** — Core Soroban contracts — Vault, agUSD, sagUSD, Allocation Engine, Oracle Adapter (Rust)  
**[agama-protocol-looping](https://github.com/agamafinance/agama-protocol-looping)** — EVM contracts (Solidity)  
**[agama-app-looping](https://github.com/agamafinance/agama-app-looping)** — Frontend application
